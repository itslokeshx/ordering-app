# 🍔 Ordering App

An interactive food ordering web app built with **HTML, CSS, and JavaScript**. This project simulates an online food ordering system where users can add and remove food items from their cart in real-time.

🔗 **Link:** [Ordering App](https://itslokeshx.github.io/ordering-app/)

---

## 🚀 Features

✅ Add food items to the cart
✅ Remove food items dynamically
✅ Real-time cart updates
✅ Simple, responsive, and user-friendly UI
✅ Built entirely with Vanilla JavaScript (no frameworks)

---

## 🛠️ Tech Stack

* **HTML5** – structure of the app
* **CSS3** – styling and layout
* **JavaScript (Vanilla JS)** – dynamic add/remove cart functionality

---

## 📦 Installation & Usage

You can try it out locally:

```bash
# Clone the repository
git clone https://github.com/itslokeshx/ordering-app.git  

# Navigate into the project folder
cd ordering-app  

# Open index.html in your browser
```

Or just open the **live demo**: [Ordering App](https://itslokeshx.github.io/ordering-app/)
